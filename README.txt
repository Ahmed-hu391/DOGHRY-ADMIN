دُغري — لوحة الإدارة

الملفات:
- index.html: صفحة تسجيل الدخول ولوحة الإدارة.
- admin.js: منطق Supabase Auth وقراءة/تعديل/حذف المساهمات.

التشغيل:
1) ضع الملفات معًا.
2) افتح index.html أو ارفع المجلد على الاستضافة.
3) سجّل الدخول بنفس مستخدم Supabase الموجود عندك في Authentication > Users.

مهم:
- الكود يستخدم Publishable Key فقط داخل المتصفح.
- لا تضع Secret/Service Role Key في أي ملف.
- الصفحة مصممة Mobile-first وتدعم Dark/Light Mode.
- قاعدة البيانات المستخدمة هي مشروع Doghry الحالي.

الصلاحيات الحالية في قاعدة البيانات تسمح لأي مستخدم Supabase authenticated بالوصول لصفوف contributions حسب السياسات التي تم إنشاؤها. لو هيتعمل حسابات متعددة لاحقًا، اعمل RLS لدور admin قبل الاستخدام الإنتاجي.
